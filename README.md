# Rooms and Flooring Matter

RimWorld 1.6 mod: room and flooring bonuses for bedrooms, barracks, Hospitality guest rooms, workshops, dining, prisons, and Biotech deathrest chambers.

**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3553076575

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- Biotech (optional — deathrest chamber bonus soft-loads)

## Build

```bash
dotnet build Source/RoomsAndFlooringMatter.csproj -c Release
```

Output: `Assemblies/RoomsAndFlooringMatter.dll`
